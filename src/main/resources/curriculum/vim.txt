# Vim track. Ordered from absolute beginner to master.
# Each @ex has a reference "solution" that the test suite replays to prove the drill is solvable.
# The par (keystroke target) defaults to the length of the solution.

@unit V1 | Survival: modes and movement
desc: Vim is modal. In NORMAL mode every key is a command; in INSERT mode keys type text. Learn to move without arrow keys and to escape.

@lesson V1.1 | Move with h j k l
intro: You start in **NORMAL** mode. Keys here are commands, not text.
intro: `h` = left, `j` = down, `k` = up, `l` = right. Keep your fingers on the home row: `j` looks like a down arrow.
intro: The goal marker (green box) shows where the cursor must end up.
keys: h j k l

@card vim | Reach the variable
task: Move the cursor onto the `b` of `int b`.
hint: Press j once to go down, then l to move right.
solution: jllll
goal: 1 4
start:
int a = 1;
int b = 2;
int c = 3;
@end

@card vim | Climb back up
task: Move up to the `c` of `class`.
hint: k moves up (three times). h moves left.
solution: kkkhh
cursor: 3 9
goal: 0 7
start:
public class Point {
    int x;
    int y;
    int z = 0;
}
@end

@card vim | Delete a typo with x
task: Remove the extra `m` so it reads `System`.
hint: Move with l, then x deletes the character under the cursor.
explain: x is "cut one character". It is the smallest deletion in Vim.
solution: lllllx
start:
Systemm.out.println("Hi");
@end
target:
System.out.println("Hi");
@end

@lesson V1.2 | Counts
intro: Almost every command accepts a **count** in front: `4j` moves down 4 lines, `3x` deletes 3 characters.
intro: Counting is faster than tapping. The editor shows relative line numbers so you can read the count off the gutter.
keys: [count]j  [count]l  [count]x

@card vim | Jump with a count
task: Put the cursor on the `t` of `target`.
hint: Read the relative number in the gutter: 4j, then 8l.
solution: 4j8l
goal: 4 8
start:
public class Main {
    // one
    // two
    // three
    int target = 42;
}
@end

@card vim | Delete several characters
task: Remove the `xxx` garbage.
hint: The cursor is already on the first x. Use a count with x.
solution: 3x
cursor: 0 4
start:

@end
target:

@end

@lesson V1.3 | Insert mode and Escape
intro: `i` enters **INSERT** mode before the cursor. Type your text, then press `Esc` to return to NORMAL mode.
intro: Build the reflex: type, then Esc immediately. `Ctrl-[` also works as Escape and keeps your hands on the keyboard.
keys: i  Esc

@unit V3 | Word motions
desc: Move by words instead of characters: w b e for words, W B E for WORDS, 0 ^ $ for line positions.

@lesson V3.1 | w, b and e
intro: `w` jumps to the start of the next word, `b` back to the start of the previous word, `e` to the end of the word.
intro: A **word** is letters/digits/underscore, OR a run of punctuation. So `a.b` is three words.
intro: Combine with counts: `3w`.
keys: w  b  e

@unit V4 | The grammar: delete + motion
desc: Vim commands are sentences: operator + motion. d (delete) works with every motion you know.

@lesson V4.1 | d + motion
intro: **Operator + motion** is the core of Vim. `d` is the delete operator: `dw` deletes a word, `de` to the end of the word, `db` backwards, `d$` to end of line, `d0` to start.
intro: `D` is a shortcut for `d$`.
intro: Learn the operators and motions separately; they multiply: 3 operators x 10 motions = 30 commands.
keys: dw  de  db  d$  D  d0

intro: `s` substitutes one character (`cl`).

@unit V7 | Undo, redo and the dot command
desc: u undoes, Ctrl-r redoes. The dot command . repeats your last change: the most powerful key in Vim.

@lesson V7.1 | u and Ctrl-r
intro: `u` undoes the last change (an entire insert session counts as one change). `Ctrl-r` redoes.
intro: Do not fear mistakes: fix them with u.
keys: u  Ctrl-r

@card vim | Undo a mistake
task: Delete the middle line. Practice: first delete the first line by "mistake" (dd), undo it (u), then delete the right one.
hint: The final text is all that is checked, but practice the undo!
solution: jdd
start:
keep me
delete me
keep me too
@end
target:
keep me
keep me too
@end

@lesson V7.2 | The dot formula
intro: `.` repeats the last change. The **Dot Formula**: one keystroke to move, one keystroke to execute.
intro: Make your change repeatable (e.g. `A;<Esc>` instead of moving to the end and typing), then use `j.` `j.`
intro: Insert sessions, `dw`, `cw...<Esc>`, `>>`, `x` ... everything that changes text can be dot-repeated.
keys: .
