@lesson J11.1 | Layout managers
book: Chapter 11, sections 11.1-11.2
@card read | Let the layout place things
text: Do not position components by pixels. A **layout manager** arranges them and adapts when the window resizes.
text: - `FlowLayout`: left to right, wrapping (default for JPanel).
text: - `BorderLayout`: NORTH, SOUTH, EAST, WEST, CENTER (default for frames).
text: - `GridLayout`: equal cells. `GridBagLayout` / `BoxLayout`: flexible grids and rows.
code:
JPanel panel = new JPanel(new BorderLayout());
panel.add(new JLabel("Title"), BorderLayout.NORTH);
panel.add(new JScrollPane(new JTextArea()), BorderLayout.CENTER);
@end
@card quiz | Which layout gives the CENTER region all the extra space?
option: FlowLayout
option*: BorderLayout
option: GridLayout
explain: In BorderLayout the edges get their preferred size and CENTER takes the rest.

@lesson J11.3 | Menus and dialogs
book: Chapter 11, sections 11.5-11.7
@card read | Menus
code:

JMenu file = new JMenu("File");

open.addActionListener(e -> openFile());
file.add(open);
bar.add(file);
frame.setJMenuBar(bar);
@end

@end
